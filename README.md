# To-Do List REST API

## Description
A simple REST API developed using ASP.NET Core Web API and C#.

## Technologies Used
- C#
- ASP.NET Core Web API

## Features
- GET: Retrieve all tasks.
- GET by ID: Retrieve a specific task.
- POST: Create a new task.
- PUT: Update an existing task.
- DELETE: Remove a task.

## Storage
Uses an in-memory static list to store tasks.

## Testing
Tested the API endpoints using Postman, including GET, POST, PUT, and DELETE operations.



## How to Run

1. Clone this repository.
2. Open the project folder.
3. Run the following command:

dotnet restore
dotnet run

4. Open the Swagger URL displayed in the terminal
   (if Swagger is configured).
